# Group Mini Project

1. Please create a group. One group consists of 4-5 students.
2. Please take a problem case with a secondary dataset.
3. Please develop neural network and/or deep learning models to tackle the problem case.
4. Please conduct comprehensive experiments to find the best models.
5. Please write your report in slides and give a presentation on **Saturday, 17 Oct 2026**.
   - Slide page 1: Identity of each group member
   - Slide page 2: Job description for each group member
   - Slide page 3: Description of the problem case
   - Slide page 4: Description of the data that you used, splitting methods, k-fold?
   - Slide page 5: Architecture of neural networks/deep learning
   - Slide page 6: Learning strategy that you used, parameter tuning
   - Slide page 7-9: Results of experiments
   - Slide page 10: Conclusion
   - Slide page 11: The URL of your code
   - Slide page 12: References
6. The presentation session for each group:
   - Presentation: 10 minutes
   - QA: 5 minutes
